Plugin for CudaText
Display in sidebar showing the number of days until the New Year, along with details on how it is celebrated in various countries around the world.

By default, the plugin only operates in December.
If you would like it to be displayed at all times - change the parameter "only_in_december" from 1 to 0 in the plugin-settings.
